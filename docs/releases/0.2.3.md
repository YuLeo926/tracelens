# TraceLens 0.2.3

## Changes

- Clearer ChatGPT desktop / Codex local MCP setup, including manual registration and a tool-call verification checklist.
- New `tracelens check` command tests installed assets, discovery, parsing, MCP stdio, and authenticated viewer access without a model call or configuration changes.
- Session keyword, date, and observed-signal filters; compact MCP session lists with detailed evidence available on demand.
- Responsive evidence-first viewer, persistent session filters, keyboard navigation, and focused event search.
- Reviewed snapshot exports with best-effort secret and path masking, explicit confirmation, and clearer cost-coverage labels.
- Metadata-only live polling for unchanged files, more robust session scanning, and fixes for usage and lifecycle handling.
- Fixed redaction of serialized viewer traces corrupting JSON containing escaped quotes.
- Updated compatible development dependencies to resolve six audit entries. Production dependencies have no known audit findings at verification time.

## Upgrade

Inspect the existing registration before replacing it:

```bash
codex mcp get tracelens --json
npx @yuleo/tracelens@0.2.3 setup codex --force
```

Use `--force` only when replacing that registration is intended. Enable and restart TraceLens in the desktop app, then start a new local Codex task. Source-checkout users can keep their existing absolute-path registration and rebuild instead.

## Verification Boundary

Automated tests and an MCP client/browser integration check are not proof that a desktop task has loaded the tools. Verify `list_sessions`, `get_session_overview`, `get_event_detail`, and `get_viewer_link` in the intended client and confirm that the linked event matches the cited evidence.

## Known Limitations

- Very large logs can still load slowly. Incremental parsing and event-list virtualization are deferred.
- Ordinary ChatGPT conversation history and ChatGPT account-history exports are not supported.
- Export masking is best effort; private prose and code can remain. Review before sharing.
- Costs are estimates from the bundled pricing table, not bills; missing usage is not zero cost.
- One low-severity development-only esbuild advisory remains in tsup's pinned compatible range. It affects esbuild's Windows development server, which TraceLens does not expose; resolving it requires a separately tested build-tool upgrade.
