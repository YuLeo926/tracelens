# TraceLens 0.2.4

## Performance Fix

- Opening or refreshing a cited event no longer waits for discovery and parsing of other sessions. The session list loads when the picker opens, with separate loading/error state and protection against stale responses.
- On the same 35,256,266-byte log, three local refresh-to-selection observations changed from 9,592 / 1,956 / 1,917 ms to 2,215 / 1,491 / 1,562 ms. Cache state and machine load were not controlled; this is not a guaranteed speedup or a general large-log parsing optimization. See the [measurement details](0.2.3-verification.md#targeted-refresh-performance-fix).
- Regression tests cover list-independent event loading, picker failure/reopen recovery, and stale responses.

## Documentation

- README retains the local agent log viewer + MCP evidence-tool positioning and a one-line maintenance notice. Detailed product evaluations are in [evaluation.md](../evaluation.md), with methods, thresholds, results, and limitations.
- Added the standalone rework-analysis script to the source repository after privacy review. Only aggregate evaluation results are public; original reports and generated evidence remain in ignored local output. The script is not included in the npm package.
- Desktop MCP-to-viewer acceptance and performance measurements are recorded; setup examples now pin 0.2.4.
